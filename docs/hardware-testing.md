# 九号车辆首轮实车验收

首轮验证 iPhone 上的 GATT 服务和公开标准读数。准备一台 iPhone、Bluefy、可信的 HTTPS 地址和有权限测试的车辆。可以用 Nordic nRF Connect 或 LightBlue 对照服务枚举结果。

1. 在 Bluefy 打开 NineLab 的 HTTPS 地址，确认页面检测到安全上下文与 Web Bluetooth。
2. 在「蓝牙筛选」选搜索范围，再点「搜索蓝牙设备」。iPhone 默认用只预申请 BFG 通道的兼容搜索。测试「仅 BFG 广播服务」、「按名称前缀」和「全部附近 BLE 设备」时，若列表为空，切回兼容搜索核对。记录日志中的搜索方式与错误类型。
3. 查看是否进入「已连接 · 未认证」。在「诊断」展开可见服务，记录所需 UUID、特征及属性。不同工具顺序连接，避免同时占用蓝牙。
4. 在常显的「车辆配对与认证」区按车辆状态操作。发现 BFG 通道后，使用已有密钥认证，或对车端未保存密钥的车辆生成密钥并配对。按仪表提示确认，核对「车辆已认证」状态后再点「读取车辆数据」。如设备公开标准字段，也可检查 180F/180A。
5. 检查通知、时间戳和断线状态，验证旧读数是否移除、前台自动重连是否最多尝试一次。
6. 在「诊断」中导出 JSON，检查文件分享和存储。对比官方 App 读数时，先在设备本地核对，只分享定位问题所需的信息。

公开报告可记录浏览器版本、GATT UUID、认证所处阶段、读取结果和故障步骤。配对密钥及个人设备标识应留在本机。
