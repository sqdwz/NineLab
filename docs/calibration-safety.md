# 校准与备份机制

- **实车** GATT 侧只有发现、标准读取和标准电量通知。专有认证、配置写入、参数恢复均未启用。
- **演示** 允许对虚拟计量模块的三个容量档位做预览。前置条件为演示授权、静止确认和独立操作确认。执行时暂停自动读取，重新核对身份、固件、当前值和参数白名单，首先将快照提交到 IndexedDB。
- **一致性** 未完成备份时流程终止。写入仅尝试一次，回读会比对档位与配置容量。回读失败、身份变化或结果不一致时，显示结果未确认。演示的当前参数为内存状态，重新加载页面会重置。
- **恢复** 验证 JSON 结构、协议版本、原始字节、SHA-256、设备身份、固件及目标值。恢复前保存新快照。备份库按唯一 ID 追加，重复导入不会覆盖原始文件。
- **后续门槛** 实车特有的写入要对应确切车型和固件、验证持久化、预备同车原始参数、核验恢复顺序及部分成功的表示。公开项目的档位列表及其他车型的回读行为只能作为输入证据。电压、保护参数和动力控制不属于 NineLab 的校准功能。

备份结构的 SHA-256 用于发现在存储或传输中被更改的内容。它不承担签名或来源认证。App 的诊断导出中不包含设备序列号，真实标准读数 CSV 同样隐去序列号。
